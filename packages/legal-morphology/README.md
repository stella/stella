# @stll/legal-morphology

Legal search morphology: Snowball stemmers, Czech/Slovak stemming, function words, expansion dictionary, and corpus tokenization.

## What lives here

Corpus tokenization, language-to-morphology mapping, Snowball and Slovak stemmers, per-language function-word lists, expansion dictionary serialization/parsing, and the tests and conformance fixtures that pin their behaviour.

## What does not

Anything outside that concern: app-specific index wiring, query execution, passage highlighting, and code another package already owns.
