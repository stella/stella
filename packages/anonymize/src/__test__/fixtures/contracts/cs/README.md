# Czech contract fixture provenance

The `.txt` fixtures in this directory are text extractions used for regression
tests. Their paired `.snapshot.json` files are generated test output. New
fixtures should be minimal and synthetic, as described in
[`CONTRIBUTING.md`](../../../../../../../CONTRIBUTING.md).

The real-world fixtures were extracted from public records in the Czech
Republic's official [Registry of Contracts](https://smlouvy.gov.cz/). These
links identify the exact source records:
