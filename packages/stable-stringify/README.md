Deterministic string form of any value, for fingerprints and cache keys that must agree across environments.

## What lives here

Deterministic string form of any value, for fingerprints and cache keys that must agree across environments, and the tests that pin its behaviour.

## What does not

Anything outside that concern: app-specific wiring, one-off helpers, and
code another package already owns.
