# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/ai-catalog](https://github.com/stella/stella/blob/v0.9.87/packages/ai-catalog/CHANGELOG.md): Offer Gemini 4 Neon on the Google and OpenRouter routes with its upstream rates, context window and generated capabilities. The offered model id types and option lists change with it, so code that matches them exhaustively has to handle the new id.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.87/packages/ui/CHANGELOG.md): Add an inline skeleton for use inside text and controls. Support shared layout and size options on button and input faces, and expose the shared one-time-code group and slot face through `@stll/ui/input-otp-face`.
- [@stll/auth-model](https://github.com/stella/stella/blob/v0.9.87/packages/auth-model/CHANGELOG.md): Align the schema contract version with Better Auth 1.7.25 after verifying the core and organization schemas are unchanged. `BETTER_AUTH_CONTRACT_VERSION` and `BETTER_AUTH_PARITY_MANIFEST.betterAuthVersion` now carry the literal `"1.7.25"`; no entrypoints are removed.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.87/packages/cli/CHANGELOG.md): `case-law ingestion-get` states, per source, whether it is parked: failing the same way for so long that it asks its publisher once a day, since when, and when it asks next.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.87/packages/cli/CHANGELOG.md): `case-law search` describes `strict` as every word, not necessarily adjacent, and a page ranked by score reports its partial matches as `partial_matches_ranked` instead of saying they were appended after the full ones.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.87/packages/ui/CHANGELOG.md): `@stll/ui/control-face` draws the faces of controls for a loading view, from the classes the real controls are built from: `ButtonFace` (and `buttonFaceClassName` for a face a caller restyles), `InputFace`, `SplitButtonFace` and `FaceLabelPending`, a bar where a control's label waits on data. The button's size and variant classes move to `button-classes.ts`, which `Button` builds its variants from, and the split button's part classes are shared the same way. `@stll/ui/list-shell` holds the grouped list's group, header, title and surface with no popup, so a pending view can import it; `@stll/ui/list` re-exports them. It adds `ListItemSkeleton`, a row's placeholder at `ListItem` geometry, and `ListGroupTitlePending`. The composer tokens add `COMPOSER_STATUS_ROW_CENTERED_CLASS` and `COMPOSER_STATUS_ROW_CLASS`, which `ComposerStatusRow` renders from.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.87/packages/ui/CHANGELOG.md): `CourtBadge` and `DocumentIdentityBadge` take `size="prose"` for a badge inside running text: it uses the text's own face with tabular numbers instead of the monospaced face badges keep in columns.
- [@stll/agent-input](https://github.com/stella/stella/blob/v0.9.87/packages/agent-input/CHANGELOG.md): `normalizeEli` takes `urnPrefixes`: a work named by a URN under one of them (a publisher without ELIs) is read as that URN, in any case and with surrounding space trimmed, and a citation the caller reads as such a URN is accepted.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.87/packages/ui/CHANGELOG.md): `@stll/ui/icons` adds `FollowUpIcon`, the arrow that leads a suggested next question under an answer.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.87/packages/cli/CHANGELOG.md): The `guidance search` and `guidance read` descriptions name the tax and administrative authorities the guidance corpus covers, and the authority filter's example names `cz-gfr`.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.87/packages/ui/CHANGELOG.md): `@stll/ui/landing-shell` holds the landing's layout and sections without the row text, so a pending view can import it cheaply; `@stll/ui/landing` re-exports it. It adds pending pieces on the landing's own geometry: `LandingRowsPending` (placeholder rows on a `LandingItemText` row's lines, optionally announced as a busy region), `LandingSectionHeadingPending` and `LandingBoxPending` (the hero box, built from the composer tokens).
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.87/packages/ui/CHANGELOG.md): Add `@stll/ui/table-shell` for rendering table headers, cells, and skeleton rows before interactive controls mount. The existing table entry point continues to expose sortable headers and truncated cells.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.87/packages/cli/CHANGELOG.md): Statute reads answer a work held only as published with that text, labelled `expressionKind: promulgated`. Provision reads carry `expressionKind` and `windowDisposition`.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.87/packages/cli/CHANGELOG.md): Content reads of a data-box file list its filed attachments as `attachments`, each with its one-based `position` in the envelope and its `entityId`.
- [@stll/scan-engine](https://github.com/stella/stella/blob/v0.9.87/packages/scan-engine/CHANGELOG.md): Rebuild the WebAssembly engine with Rust 1.100.0.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.87/packages/cli/CHANGELOG.md): The capability catalog lists `skills.export`, which downloads a skill as an Agent Skills archive (a ZIP with one folder named after the skill, holding `SKILL.md` and every resource file). It returns file bytes, so the generic `stella capability` transport does not run it; `skills get` covers the skill as JSON.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.87/packages/ui/CHANGELOG.md): Add a ZFO document mark for Czech data-box files.
- [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.87/packages/workspace-ui/CHANGELOG.md): Add `@stll/workspace-ui/view-switcher-face`: `WorkspaceViewSwitcherFace` draws the saved-view strip without its behaviour, for a loading view, and `WorkspaceViewStrip` and `WorkspaceViewTabFace` are the row and tab both switchers share.
