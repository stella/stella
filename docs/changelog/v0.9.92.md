# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.92/packages/cli/CHANGELOG.md): A document's version history names where a file the member's browser downloaded for a chat came from (`browserDownload`).
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.92/packages/cli/CHANGELOG.md): Transcribe a recording in a matter (`recording-transcriptions runs-create`) and follow the run (`recording-transcriptions runs-get`); the transcript is saved beside the recording.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.92/packages/ui/CHANGELOG.md): Add the React Native `ComposerFrame` (`@stll/ui/composer-frame` on native) with the web frame's prop contract: one bar while the text fits a line, then the text across the box over a control row, back to the bar only when the draft is empty. Web and native share one layout state machine and one 320 cap token (`COMPOSER_TEXT_REGION_MAX_HEIGHT_CLASS`). The native `Textarea` takes `appearance="composer"`, which grows to the frame's cap and scrolls itself.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.92/packages/ui/CHANGELOG.md): Add `ComposerFrame` (`@stll/ui/composer-frame`): the one composer box, which owns its layout. A compact composer is one bar while its text fits a line, then the text across the box over a control row once it needs a second line, and back to the bar only when the draft is empty; a large one is always text over the control row. The text grows to 320px and then scrolls in its own region, with the scroll area's edge scrollbar and fades, outside the controls and the attachments. The layout tokens (`COMPOSER_COMPACT_ROW_CLASS`, `COMPOSER_COMPACT_TEXT_CELL_CLASS`, `COMPOSER_LARGE_TEXT_WELL_CLASS`, `COMPOSER_LARGE_EDITOR_CLASS`, `COMPOSER_LARGE_ACTION_ROW_CLASS`, `COMPOSER_LEADING_GROUP_CLASS`, `COMPOSER_PLACEHOLDER_CLASS`, `COMPOSER_BOX_FOCUS_CLASS`, `COMPOSER_BOX_ANONYMIZED_CLASS`) and `ComposerPlaceholder` are no longer exported; `@stll/ui/composer` no longer re-exports `COMPOSER_BOX_CLASS`. `DOC_FLOAT_SURFACE_CLASS` moves to `@stll/ui/composer-tokens`. `Textarea`'s `composer` appearance no longer sets a height floor: the frame does.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.92/packages/ui/CHANGELOG.md): `DayCalendarBlock` gains the `scheduled` kind, drawn as an outline, and `DayCalendarColumn` gains an optional `narrow` width, so planned time can be drawn beside recorded time in `@stll/ui/day-calendar`. Code that switches over every block kind needs a case for it. No entrypoint is removed.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.92/packages/ui/CHANGELOG.md): `DayCalendarBlock` gains the `unrecorded` kind, drawn hatched, for time that should have been recorded and was not. Code that switches over every block kind needs a case for it. No entrypoint is removed.
- [@stll/docx-utils](https://github.com/stella/stella/blob/v0.9.92/packages/docx-utils/CHANGELOG.md): Build on `@stll/docx-core` 0.45.1.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.92/packages/ui/CHANGELOG.md): `FileAudioIcon` marks an audio file.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.92/packages/ui/CHANGELOG.md): `MenuRadioItem` takes `appearance="segment"`, which lays a group's choices out as one segmented control: the chosen one is raised and no check mark is drawn.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.92/packages/ui/CHANGELOG.md): `SettingsRow` starts its footer on the title's edge when the row has media, so every line of the row's text shares one start edge, and takes an optional `target`: the row then carries `data-settings-target`, can take focus from script, and is marked while `data-highlighted` is set, for a settings link that brings it into view.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.92/packages/cli/CHANGELOG.md): Add `stella site-notes save` to add, confirm, replace or remove the research notes an agent keeps about how a research website works.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.92/packages/ui/CHANGELOG.md), [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.92/packages/workspace-ui/CHANGELOG.md): `SidebarProvider`, `DetailsGrid`, `EntityActions`, the native `Sheet` and `ConditionBuilder` keep their context values stable across renders, so a re-render of the provider no longer re-renders every consumer in an app that does not use the React Compiler.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.92/packages/ui/CHANGELOG.md): `Switch` draws on as a green track and off as a grey track, both under a white thumb, from the new `--switch-track`, `--switch-track-checked` and `--switch-thumb` theme tokens (`bg-switch-track*`, `bg-switch-thumb`). Each track stands at least 3:1 against the page, cards and popovers in every palette. `SwitchFace` and the native `Switch` use the same tokens.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.92/packages/ui/CHANGELOG.md): `@stll/ui/effects-dom` keeps React state from the DOM without effect loops: `useObservedValue` (the primitive, with an equality guard and a breaker for layout feedback), `useLayoutMeasurement`, `useElementSize`, `useIntersecting` and a shared, reference-counted `useObjectUrl`. `@stll/ui/effects` adds `useNow`, one shared clock per interval.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.92/packages/ui/CHANGELOG.md): The sanctioned React effect hooks are exported from `@stll/ui/effects`: `useMountEffect`, `useExternalSyncEffect`, `useLayoutSyncEffect` and `useMountLayoutEffect` for syncing with systems outside React, `useLatest` and `useLatestCallback` for reading the latest committed value or callback (`useLatestCallback` keeps one identity whether or not the React Compiler runs), `useIsMounted` and `useHasMounted` for mount state, and `useKeyedState` for local state that starts over when a key changes. `@stll/ui/use-latest` now resolves to the same module.
