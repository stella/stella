# Citations on case-law decisions

## See how a decision has been treated

Every public decision page now lists the decisions that cite it and the
decisions it cites, grouped by treatment, with negative treatment first. A
small strip in the header shows citations per year, so you can see whether a
decision is still relied on and when criticism began.

Citations inside the decision text link to the cited decision, with a preview
on hover. Where one case number covers several documents, each is labelled
with its type and year.
