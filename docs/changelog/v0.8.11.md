# Take a conversation in a new direction

## Start a separate chat from any answer without losing the original.

Open an answer’s menu and choose **Start a new chat from here**. stella carries the conversation up to that point into a separate chat, including its attachments. The original stays unchanged, and the new chat links back to where it started.
