# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/auth-model](https://github.com/stella/stella/blob/v0.9.76/packages/auth-model/CHANGELOG.md): Align the schema contract version with Better Auth 1.7.16 after confirming the core and organization schemas are unchanged. `BETTER_AUTH_CONTRACT_VERSION` and `BETTER_AUTH_PARITY_MANIFEST.betterAuthVersion` now carry the literal `"1.7.16"`; no entrypoints are removed.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.76/packages/cli/CHANGELOG.md): `search_case_law` returns the phrasings that finished when another phrasing runs out of its time budget; that phrasing reports a `time_budget` truncated outcome and a `phrasing_timed_out` warning instead of failing the call.
- [@stll/chat](https://github.com/stella/stella/blob/v0.9.76/packages/chat/CHANGELOG.md): `ChatLink` takes a `fullLabel` option for tray chips whose label should keep the available width instead of the compact 20-character cap, and a tray chip's site icon is now centred on the label.
- [@stll/chat](https://github.com/stella/stella/blob/v0.9.76/packages/chat/CHANGELOG.md), [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.76/packages/workspace-ui/CHANGELOG.md): `ChatModelSelector` now renders the `@stll/ui` select (a button and a popup list) instead of a native `<select>`: a host must load the `@stll/ui` stylesheet (`@stll/ui/theme.css` with Tailwind scanning `@stll/ui`) for it to draw. `ChatLink` shows its new-tab notice or source title as a tooltip and as the link's accessible description. The condition builder's number fields use `NumberInput` without locale grouping.
- [@stll/chat](https://github.com/stella/stella/blob/v0.9.76/packages/chat/CHANGELOG.md): Update compatible editor dependencies.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.76/packages/ui/CHANGELOG.md): `DayCalendar` blocks take a `topic` tone: a lighter tint from the matter palette, keyed by a stable topic key and drawn without a matter's edge. `mixed` blocks no longer draw diagonal stripes.
- [@stll/scan-engine](https://github.com/stella/stella/blob/v0.9.76/packages/scan-engine/CHANGELOG.md): Refresh generated WebAssembly for the pinned Rust compiler.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.76/packages/ui/CHANGELOG.md): Add `TimeField` and `TimeFieldGroup` (`@stll/ui/time-field`): a wall-clock time to the minute as hour and minute selects in the locale's own clock and numerals. Fields in one `TimeFieldGroup` share a grid, so their labels, hours and minutes line up; in a narrow container each label moves above its selects, which never shrink below their value. The date picker's time row now uses it.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.76/packages/ui/CHANGELOG.md): Add `AnimatedPreview` (`@stll/ui/animated-preview`): a frame of ordered stages that cross-fade into each other once or in a loop, nestable inside a stage, with `AnimatedPreviewMotion` for a carry gesture and `AnimatedPreviewCard` for a hover and focus preview that describes its trigger. Reduced motion shows the final stage statically; the styles ship through `@stll/ui/theme.css`, and `@stll/ui/use-prefers-reduced-motion` exports the preference hook.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.76/packages/ui/CHANGELOG.md): Add `DocumentMark` (`@stll/ui/document-mark`), a file format's mark (PDF, Word, Excel, PowerPoint, RTF, ODT, ODS, CSV, Markdown) drawn from one artwork source, with a React Native renderer under the `react-native` condition.
