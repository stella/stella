# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.89/packages/cli/CHANGELOG.md): Uploads of `.heic` and `.heif` photos declare `image/heic` and `image/heif`.
- [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.89/packages/workspace-ui/CHANGELOG.md): `FileConversionRefusal` adds `{ kind: "no_preview", format, cause }`: an image this deployment makes no preview of, because it does not decode the format (`"decoding_off"`) or cannot read the file's pictures (`"unreadable"`). `format` is the file's short tag, such as `"HEIC"`.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.89/packages/ui/CHANGELOG.md): Keep a gutter between body columns of a compact table, as its header already has.
