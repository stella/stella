# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.89/packages/cli/CHANGELOG.md): Uploads of `.heic` and `.heif` photos declare `image/heic` and `image/heif`.
- [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.89/packages/workspace-ui/CHANGELOG.md): `FileConversionRefusal` adds `{ kind: "no_preview", format, cause }`: an image this deployment makes no preview of, because it does not decode the format (`"decoding_off"`) or cannot read the file's pictures (`"unreadable"`). `format` is the file's short tag, such as `"HEIC"`.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.89/packages/ui/CHANGELOG.md): Keep a gutter between body columns of a compact table, as its header already has.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.89/packages/cli/CHANGELOG.md): Read Outlook TNEF messages (`winmail.dat`), alone or attached to an email, through document content commands.
- [@stll/anonymize-chat](https://github.com/stella/stella/blob/v0.9.89/packages/anonymize-chat/CHANGELOG.md): Run on version 4.0.0 of `@stll/anonymize-wasm`.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.89/packages/cli/CHANGELOG.md): The `matters.correspondence.get` and `matters.correspondence.list` references describe `pec` records: uploaded Italian certified emails whose `certifiedEmail` carries the provider's certification data as stated in the file.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.89/packages/cli/CHANGELOG.md): Read mailboxes (`.mbox`) through document content commands: each message's sender, recipients, date, subject, text and attachments' names.
- [@stll/chat](https://github.com/stella/stella/blob/v0.9.89/packages/chat/CHANGELOG.md), [@stll/ui](https://github.com/stella/stella/blob/v0.9.89/packages/ui/CHANGELOG.md): Update `@ag-ui/core` to `1.0.5`. Update `tldts` to `7.5.4`. Update `lucide-react` to `1.74.0`.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.89/packages/ui/CHANGELOG.md): Add a shared web and native document mark for mailboxes (`.mbox`).
