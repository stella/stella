# Maintenance release

Stella includes reliability and maintenance improvements.

## Packages

- @stll/ai-catalog: Keep the rate and the streaming tool-use limit of `us.deepseek.r1-v1:0` for deployment overrides that still select it.
- @stll/ai-catalog: Stop offering `us.deepseek.r1-v1:0` on Bedrock. The model accepts no tool definitions, and every model role sends tools or structured output.
- @stll/cli: Capabilities that create or change documents now require `stella:documents_write`, the consent the named document tools already required: `entities.upload`, `entities.versions.upload`, `entities.bilingual.create`, `entities.from-legal-source.create`, `entities.versions.restore`, `document-translations.runs.create`, and `fields.kanban-placement.update`. `entities.duplicate` and `entities.copy` require it in addition to `stella:matters_write`. Document uploads through `uploads.create` and `uploads.update` require it too, and `stella upload` checks for both scopes before starting a new document.
- @stll/cli: `stella feedback submit` takes the `approval_token` that `stella feedback prepare` returns; the server refuses a report the token does not cover. Key-value output no longer truncates values without whitespace (tokens, ids, URLs), so they can be copied at any terminal width.
- @stll/cli: Capability ids name nested resources: `<domain>[.<resource>…].<action>`, where the action is `list`, `get`, `create`, `update`, `delete`, or a single-word domain verb. Compound actions moved into the resource path, so some `invoke_capability` ids and generated command names changed; the `@stll/cli` 2.0.0 changelog lists every previous and current id. The previous ids are not accepted; an unknown id's error suggests the closest current ids.
- @stll/cli: `annotation list|create|update|delete` reads and writes highlights and comments on case-law decisions and statute versions.
- @stll/ui, @stll/workspace-ui: Export the inspector layout tokens as `@stll/ui/layout-tokens`, and export the shared field-value parts (`formatIntFieldValue`, `PersonAvatar`, `PendingSkeleton`, the empty, error, unsupported and clip renderers, and the select and int styling helpers) from `@stll/workspace-ui/field-value`.
- @stll/anonymize-chat, @stll/ui: Invalid input now raises a tagged error (`ChatAnonInputLimitError` in anonymize-chat) or a `Panic` (resource calendar) instead of a native `RangeError` or `TypeError`.
- @stll/cli, @stll/ui: Template and capability commands advertise the input bounds and defaults the server already enforced. `DestructiveConfirmDialog` reports an unexpected confirm rejection instead of dropping it.
