# Maintenance release

Stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.41/packages/cli/CHANGELOG.md): Clarify delivery authentication and asserted headers in correspondence capability descriptions.
- [@stll/business-registries](https://github.com/stella/stella/blob/v0.9.41/packages/business-registries/CHANGELOG.md): Update `fast-xml-parser` to `^5.11.1`.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.41/packages/cli/CHANGELOG.md): `lists items-list` describes each item's first source (document id, document name, locator).
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.41/packages/ui/CHANGELOG.md): Add `TextMark` and `textMarkClass` (`@stll/ui/text-mark`): one inline mark for words in running text, with `fill`, `underline`, `dotted`, `wavy` and `strike` variants, semantic and option-palette tones, and `rest`, `matched` and `active` states. `SEARCH_HIT_MARK`, `SEARCH_HIT_DESCENDANT_MARK_CLASS` and `textMarkHighlightRule` carry the search-hit mark to pre-highlighted markup and the CSS Custom Highlight API.
