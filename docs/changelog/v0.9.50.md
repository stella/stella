# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.50/packages/cli/CHANGELOG.md): Document that case-law analysis generation refuses decisions in a language without an analysis prompt.
- [@stll/start-runtime](https://github.com/stella/stella/blob/v0.9.50/packages/start-runtime/CHANGELOG.md): Add a bounded local-module loader and use it to verify emitted server modules.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.50/packages/ui/CHANGELOG.md): Add a decorative Loader variant for labelled controls and use the shared Loader in Button and Toast loading states.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.50/packages/cli/CHANGELOG.md): Show deployment-gated commands only with fresh same-origin availability evidence and the caller's required feature access.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.50/packages/cli/CHANGELOG.md): Route CLI SHA-256 hashing through its local Node owner, preserving digest encodings.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.50/packages/cli/CHANGELOG.md): Request approval for tools that can modify existing records.
- [@stll/ai-catalog](https://github.com/stella/stella/blob/v0.9.50/packages/ai-catalog/CHANGELOG.md): Regenerate model catalog snapshots from committed upstream inputs during checks.
- [@stll/ai-catalog](https://github.com/stella/stella/blob/v0.9.50/packages/ai-catalog/CHANGELOG.md): Refresh the model capability snapshot so sampling parameters are omitted for models that reject them.
- [@stll/ai-catalog](https://github.com/stella/stella/blob/v0.9.50/packages/ai-catalog/CHANGELOG.md): Keep the model rate snapshot current, with reviewed price corrections pinned to the upstream values they replace.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.50/packages/ui/CHANGELOG.md), [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.50/packages/workspace-ui/CHANGELOG.md): Add `@stll/ui/inline-reorder` and `@stll/ui/inline-drop-indicator` for reordering a horizontal row of items by closest edge. `@stll/workspace-ui` now uses them for view tabs and no longer exports `reorderWorkspaceViewIds`, `toWorkspaceViewDropPosition` or the `./view-switcher-logic` entry point.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.50/packages/cli/CHANGELOG.md): Update shared list capability descriptions and caller-specific projections.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.50/packages/ui/CHANGELOG.md), [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.50/packages/workspace-ui/CHANGELOG.md): Use updated Pragmatic drag and drop dependencies and public entry points.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.50/packages/cli/CHANGELOG.md): Recognize verification run limit error codes; active run limits exit with code 4 and daily run limits with code 9.
