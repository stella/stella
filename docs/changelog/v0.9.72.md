# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/business-registries](https://github.com/stella/stella/blob/v0.9.72/packages/business-registries/CHANGELOG.md): Send Czech insolvency register queries with their criteria in the order the service schema defines, which the service now enforces.
- [@stll/text-normalize](https://github.com/stella/stella/blob/v0.9.72/packages/text-normalize/CHANGELOG.md): Preserve numeric superscript index boundaries before search query compatibility folding.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.72/packages/ui/CHANGELOG.md): Import the calendar from `@stll/ui/calendar-primitives`, `@stll/ui/resource-calendar` or `@stll/ui/resource-calendar.logic`; the `@stll/ui/calendar` barrel is removed.
