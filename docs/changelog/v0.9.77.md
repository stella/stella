# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/auth-model](https://github.com/stella/stella/blob/v0.9.77/packages/auth-model/CHANGELOG.md): The opaque organization slug's random source takes an ArrayBuffer-backed byte view, so the module type-checks under both the Node and DOM declarations of `crypto.getRandomValues`.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.77/packages/ui/CHANGELOG.md): `ColorPicker` takes its popover trigger as `trigger`, a single element that becomes the trigger itself instead of being wrapped in a second button. `children` is removed; pass `nativeButton={false}` when the trigger is not a native `<button>`.
- [@stll/docx-utils](https://github.com/stella/stella/blob/v0.9.77/packages/docx-utils/CHANGELOG.md): Use docx-core ZIP for shared bounded archive loading. Remove the JSZip-specific extraction, repacking and entry-writing helpers.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.77/packages/ui/CHANGELOG.md): Add `EntityActions` and `EntityActionsButton` (`@stll/ui/entity-actions`): an object's actions from one list, opened by its "…" button and by right-click with the same items. Shift + right-click, editable text, links and selected text keep the native menu, and a nested object answers before the one around it. `@stll/ui/native-context-menu` exports the predicates, including the narrower one a desktop webview applies. `ContextMenuActionItems` (`@stll/ui/context-menu`) renders an action list inside any menu popup.
- [@stll/scan-engine](https://github.com/stella/stella/blob/v0.9.77/packages/scan-engine/CHANGELOG.md): Document building the committed WebAssembly on any host with Docker (`build:wasm:container`) and updating crates through the release-age quarantine.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.77/packages/ui/CHANGELOG.md): The theme defines `--auth-gradient-end`, `--error-gradient-end` and `--shadow-tint`, and a `category-tile` utility that colours a tile from its `--cat-hue`.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.77/packages/ui/CHANGELOG.md): Add `portraits` and `portraitCredit` to `OutlineItem`: the people an outline entry is about. The tick stays a tick and shows them in a card on hover or focus, the panel row shows their faces, and such an entry stays on the rail however dense the outline gets.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.77/packages/ui/CHANGELOG.md): Add `@stll/ui/kbd` (key caps that spell modifiers for the reader's platform, hydration-safe), used by `MenuShortcut` and a new `TooltipPopup` `shortcut` prop. Add `MenuLinkItem`. A loading `Button` keeps its width. `Textarea` takes `maxRows` and `showCount`. `DetailsGrid` takes `orientation="auto"` (by container width) and `labelWidth`, and an item with no value draws a dash.
- [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.77/packages/workspace-ui/CHANGELOG.md): Add the `record` field content type: a cell holding typed records from a data source or a structured AI answer. `FieldValue` renders it as a summary (the record's values, a record count, a prompt to choose among unselected candidates, or a review or not-found note), and `RecordFieldValue`, `summarizeRecordField` and the `RecordField*` types are exported. `GenericProperty` and `PropertyIconType` accept `record`.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.77/packages/cli/CHANGELOG.md): Carry the current generated tool registry. No command changes.
