# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/ai-catalog](https://github.com/stella/stella/blob/v0.9.82/packages/ai-catalog/CHANGELOG.md): Offer Gemini 4 Hydrogen on the Google and OpenRouter routes with its upstream rates, context window and generated capabilities. The offered model id types and option lists change with it, so code that matches them exhaustively has to handle the new id.
- [@stll/auth-model](https://github.com/stella/stella/blob/v0.9.82/packages/auth-model/CHANGELOG.md): Align the schema contract version with Better Auth 1.7.19 after verifying the core and organization schemas are unchanged. `BETTER_AUTH_CONTRACT_VERSION` and `BETTER_AUTH_PARITY_MANIFEST.betterAuthVersion` now carry the literal `"1.7.19"`; no entrypoints are removed.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md): `lists.verifications.get` claims carry `decider`: who decided the verdict, the generative model (with the reason when the organization's decision model was asked and its answer was not used) or the decision model, with its model, confidence and the state it replaced.
- [@stll/chat](https://github.com/stella/stella/blob/v0.9.82/packages/chat/CHANGELOG.md): Use TanStack AI Client v1 for chat transport and persisted conversation replay.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.82/packages/ui/CHANGELOG.md): `@stll/ui/icons` no longer exports `ColumnsIcon`: its last use is gone, and the plain re-export list holds only the icons the workspace draws. Import it from `lucide-react` if you still need it.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md): Document uploads accept files up to 200 MiB, the server's document limit, read from the API contract instead of a copy.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.82/packages/ui/CHANGELOG.md): `EditPagesIcon` names the glyph for opening a document's pages to reorder, rotate, crop or delete them, and replaces `FilePenLineIcon`, which `@stll/ui/icons` no longer exports. `SplitButton` draws both halves in the foreground colour of other ghost buttons.
- [@stll/docx-utils](https://github.com/stella/stella/blob/v0.9.82/packages/docx-utils/CHANGELOG.md): Depends on `@stll/docx-core` 0.43.0.
- [@stll/html](https://github.com/stella/stella/blob/v0.9.82/packages/html/CHANGELOG.md): Update the HTML parser and tree adapter to parse5 8 with domhandler 6.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.82/packages/ui/CHANGELOG.md): `InlineRenameInput` keeps its 10ch floor in a fixed length that a row sized from its content measures, so a short field no longer takes width from the text beside it when it opens.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md): Preserve legal_hold_active refusals, map them to conflict exit code 10, and print each hold's scope beside its issue line.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md): `lists.verifications.get` claims carry `assertedOn`: the date the claim's words give, as `dated` with a `day`, `month` or `year` precision (stored as its first day) and its `source` (the words, or the grader when they name no complete date), or `none`. A re-check records its own reading.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md): Add `lists.verifications.claim-rechecks.bulk.create`: checks several claims of one verification again in one request, each under its own request key, and reports each claim's outcome. `lists.verifications.get` claims carry `staleness`, the reasons a claim's grade may no longer stand on the list as it is now.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md): Three read capabilities query a matter's graph of verified claims, list facts and the documents the facts come from. `lists.graph.nodes.list` finds facts, claims and documents by their words. `lists.graph.neighbours.list` reads one node's links, with a summary by kind, stance and decision and a page of edges. `lists.graph.paths.list` follows links from a node for up to three hops. Every edge comes with the exact text it rests on, who produced it and its decision, and each tool filters by edge kind, stance or decision.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md): `lists.verifications.graph.get` gives each claim the printed number of the paragraph it sits in (`paragraph`) and each source link the source's `quote`; `lists.verifications.get` gives each claim its `paragraph`.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md): Add `lists.verifications.graph.get`: reads the verification graph of one list, a page of verified documents at a time: their claims with the verdict as reviewers see it, the list's facts (held, tier, off the list), the documents those facts come from, each claim's links to the facts it cites or conflicts on, and each fact's source locators.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md): `matters.get` reads one matter, archived ones included, and `matters.contacts.list` lists a matter's parties in their roles. `matter add-member` and `matter remove-member` (and `matters.members.add`/`.remove`) now need the matters write consent instead of the admin one; who may run them is unchanged.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md): `matters.member-candidates.list` lists the people of your organization a matter can be shared with, for `matters.create` and `matters.members.add`.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md): `matters.matter-numbering.get` reads the organization's matter-number pattern and its padding, so a matter number can be checked against them without reading the organization's settings.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md): An organization's run limits answer with `run_active_limit_reached` and `run_daily_limit_reached` for list verifications, fact extractions and document reviews alike; the exit classes are unchanged.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md), [@stll/business-registries](https://github.com/stella/stella/blob/v0.9.82/packages/business-registries/CHANGELOG.md), [@stll/chat](https://github.com/stella/stella/blob/v0.9.82/packages/chat/CHANGELOG.md), [@stll/ui](https://github.com/stella/stella/blob/v0.9.82/packages/ui/CHANGELOG.md): Refresh the supported chart, editor, icon, and styling dependency versions.
- [@stll/scan-engine](https://github.com/stella/stella/blob/v0.9.82/packages/scan-engine/CHANGELOG.md): Rebuild the scanner WASM with refreshed Rust dependencies and the updated canonical toolchain.
- [@stll/chat](https://github.com/stella/stella/blob/v0.9.82/packages/chat/CHANGELOG.md): `createDurableChatTransport` gives each dropped connection its own reconnect window. A turn that stayed silent between two drops used to spend the first drop's window on the second and fail its reconnection.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md): `tasks.delete` deletes one task from its matter at the matters write consent, as `delete_task` does; anything that is not a task is not found.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md): `tasks.list` lists anyone's or unassigned tasks (`assignee`), one matter's (`matterId`), finished ones too (`openOnly=false`) and those due on or before a day (`dateTo`); without them it lists the caller's own open tasks as before.
- [@stll/chat](https://github.com/stella/stella/blob/v0.9.82/packages/chat/CHANGELOG.md): Stop reconnecting immediately when the server refuses access or returns an invalid resume response. Preserve the typed error and the transcript already received.
- [@stll/agent-input](https://github.com/stella/stella/blob/v0.9.82/packages/agent-input/CHANGELOG.md), [@stll/ai-catalog](https://github.com/stella/stella/blob/v0.9.82/packages/ai-catalog/CHANGELOG.md), [@stll/anonymize-chat](https://github.com/stella/stella/blob/v0.9.82/packages/anonymize-chat/CHANGELOG.md), [@stll/auth-model](https://github.com/stella/stella/blob/v0.9.82/packages/auth-model/CHANGELOG.md), [@stll/calculations](https://github.com/stella/stella/blob/v0.9.82/packages/calculations/CHANGELOG.md), [@stll/chat](https://github.com/stella/stella/blob/v0.9.82/packages/chat/CHANGELOG.md), [@stll/conditions](https://github.com/stella/stella/blob/v0.9.82/packages/conditions/CHANGELOG.md), [@stll/docx-utils](https://github.com/stella/stella/blob/v0.9.82/packages/docx-utils/CHANGELOG.md), [@stll/ssr-testkit](https://github.com/stella/stella/blob/v0.9.82/packages/ssr-testkit/CHANGELOG.md), [@stll/start-runtime](https://github.com/stella/stella/blob/v0.9.82/packages/start-runtime/CHANGELOG.md), [@stll/template-conditions](https://github.com/stella/stella/blob/v0.9.82/packages/template-conditions/CHANGELOG.md), [@stll/ui](https://github.com/stella/stella/blob/v0.9.82/packages/ui/CHANGELOG.md), [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.82/packages/workspace-ui/CHANGELOG.md): Build declarations through the native tsrs API supported by tsdown 0.23.7, resolving the compiler from each package.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.82/packages/ui/CHANGELOG.md): Export the cloud icon from `@stll/ui/icons`.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.82/packages/ui/CHANGELOG.md): `@stll/ui/file-size` formats a byte count in the reader's locale (`formatFileSize`, with a `use-intl` formatter) and picks its decimal unit (`getFileSizeDisplay`), for the web and the phone alike.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md): `lists.verifications.get` returns `unreadParts`: the text a completed run could not read, each from a `start` to an `end` edge (a block id and an offset). No claim was looked for there; verify the document again to read it. Empty when the run read everything.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.82/packages/cli/CHANGELOG.md): Add `stella case-law verify-quote` to check exact quotations, inspect altered passages, and distinguish unreadable decision text.
