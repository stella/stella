# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/auth-model](https://github.com/stella/stella/blob/v0.9.49/packages/auth-model/CHANGELOG.md): Update the shared auth runtime dependency.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.49/packages/cli/CHANGELOG.md): Describe declared feature policies and deployment availability in organization settings discovery.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.49/packages/cli/CHANGELOG.md): Add case-law coverage by jurisdiction, including decision counts, year ranges, and court breakdowns.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.49/packages/cli/CHANGELOG.md): `read_case_law_decision` accepts `max_chars` with several decision ids and sizes each decision's text window, up to 40000 characters per call.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.49/packages/cli/CHANGELOG.md): `read_case_law_decision` returns a compact decision paged by number (`page`, `full`, `text_version`; no `cursor`), a `query` paragraph search and a citation summary instead of raw citation rows.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.49/packages/cli/CHANGELOG.md): Report a read without text as a typed `textUnavailable` outcome instead of printing empty text, and explain missing dependencies when run from source.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.49/packages/cli/CHANGELOG.md): Include bounded court and year aggregates in first-page case-law search facets, with distinct-decision estimates and explicit unavailable citation and treatment signals.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.49/packages/ui/CHANGELOG.md): Add form dirtiness signals and a shared dialog Escape policy: unchanged dialogs close immediately; changed dialogs show a localized discard hint before a second Escape closes them.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.49/packages/cli/CHANGELOG.md): Identifier lookups include the court abbreviation.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.49/packages/ui/CHANGELOG.md): Add an inline rename field that keeps the surrounding title typography and sizes to its text.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.49/packages/ui/CHANGELOG.md): Let an inline rename field fill its row instead of sizing to its text.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.49/packages/cli/CHANGELOG.md): Preserve primary legal citation URLs and secondary publisher source URLs in JSON and JSONL text-window output.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.49/packages/cli/CHANGELOG.md): Declare feature availability and conditional inputs in the CLI capability catalogue.
- [@stll/ai-catalog](https://github.com/stella/stella/blob/v0.9.49/packages/ai-catalog/CHANGELOG.md): Offer Mistral Large 4 in the model catalog.
- [@stll/ai-catalog](https://github.com/stella/stella/blob/v0.9.49/packages/ai-catalog/CHANGELOG.md): Add `RECOMMENDED_CHAT_MODELS`, the curated list behind the chat model picker's Recommended section, and a `supersededBy` field in model display metadata that names the newer model replacing an older one.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.49/packages/ui/CHANGELOG.md): Add semantic DetailsGrid and DetailsItem primitives with container-responsive columns, aligned labels, and full-width facts.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.49/packages/cli/CHANGELOG.md): Expose sanctions monitoring decisions and review history in the CLI contract.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.49/packages/cli/CHANGELOG.md): Search tools report `search_index_unavailable` (exit code 4, retryable) when the search index cannot be reached.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.49/packages/cli/CHANGELOG.md): Accept namespaced skill tool names through a shared server and CLI naming contract, and generate command paths without leading separators.
- [@stll/template-conditions](https://github.com/stella/stella/blob/v0.9.49/packages/template-conditions/CHANGELOG.md): Expose the path utility module for shared non-null-object checks.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.49/packages/ui/CHANGELOG.md): Add a shared split button with independent actions, accessible menu navigation, and quiet hover chrome.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.49/packages/ui/CHANGELOG.md): Focus the selected or current day when opening a date picker and keep field trigger text on one line.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.49/packages/cli/CHANGELOG.md): Update the generated command contract.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.49/packages/cli/CHANGELOG.md): Respect per-user feature enrolment when discovering and invoking capabilities.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.49/packages/ui/CHANGELOG.md): Add `ToolbarIconAction`, an icon-only toolbar button whose label is its tooltip and accessible name.
