# Maintenance release

Stella includes reliability and maintenance improvements.

## Packages

- @stll/cli: `case-law search` no longer requires a question's function words. It reports `searches[].queryUsed` (the words the search required) and `searches[].warnings`, and takes `--strict` to require every word.
- @stll/workspace-ui: Keep the new-view action visible and separated from overflowing workspace tabs.
