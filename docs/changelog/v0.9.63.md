# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.63/packages/cli/CHANGELOG.md): Describe why AI is unavailable and whether the caller may configure the organization's provider in the AI availability capability.
- [@stll/auth-model](https://github.com/stella/stella/blob/v0.9.63/packages/auth-model/CHANGELOG.md): Include OAuth consent references in the authentication model contract.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.63/packages/cli/CHANGELOG.md): Case-law coverage reports each source's held decision-year range and its completeness per calendar year.
- [@stll/chat](https://github.com/stella/stella/blob/v0.9.63/packages/chat/CHANGELOG.md): Require `zod` 4.6.6 or later.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.63/packages/cli/CHANGELOG.md): Update connector tool metadata for app-only web link refresh.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.63/packages/ui/CHANGELOG.md): A host can trigger the copy button confirmation from outside its own click with `useCopiedFeedback` and `CopyFeedback`.
- [@stll/ai-catalog](https://github.com/stella/stella/blob/v0.9.63/packages/ai-catalog/CHANGELOG.md): Refresh upstream model rates and request capabilities.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.63/packages/ui/CHANGELOG.md): Name the copy glyph by meaning: `CopyToClipboardIcon` (drawn only by `CopyButton`), `CopyFromMenuIcon` and `DuplicateIcon` replace the plain `CopyIcon` export. `CopyButton` takes a `labelClassName` for its visible label, and `useCopyConfirmation` exposes its in-place confirmation for copy controls that cannot be a glyph button.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.63/packages/ui/CHANGELOG.md): Add start alignment to select triggers and remove inner horizontal padding from unstyled inputs.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.63/packages/ui/CHANGELOG.md): `@stll/ui/icons` no longer exports `BotIcon`. Use `AiActionIcon` for something the AI does and `CpuIcon` for models and providers.
- [@stll/chat](https://github.com/stella/stella/blob/v0.9.63/packages/chat/CHANGELOG.md): Adds `getChatLinkSite`, which returns the registrable domain of a link hostname so link icons can be requested once per site.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.63/packages/ui/CHANGELOG.md): Allow landing row icons to grow to fit court abbreviations.
