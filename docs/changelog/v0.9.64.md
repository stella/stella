# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.64/packages/cli/CHANGELOG.md): Recognize the `action_feature_disabled` admission refusal, returned while an operator has turned the requested feature off, and exit with the feature-disabled code.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.64/packages/cli/CHANGELOG.md): Add `stella capability` commands for document redline suggestions (`docx-suggestions list`, `resolve`, `revert`), assistant memory (`memories list`, `create`, `update`) and notifications (`notifications list`, `read-state-update`).
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.64/packages/cli/CHANGELOG.md), [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.64/packages/workspace-ui/CHANGELOG.md): Paginate filesystem tree reads and expose bounded text previews in entity lists.
- [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.64/packages/workspace-ui/CHANGELOG.md): Allow hosts to provide typed content for workspace feature previews while retaining the default scenes.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.64/packages/cli/CHANGELOG.md): Add tax ID, VAT-payer status and invoice language to contacts, a language to invoices, and a command that adds a country's VAT rates from a preset.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.64/packages/cli/CHANGELOG.md): Add the Polish KSeF FA(3) e-invoice format to invoice export.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.64/packages/ui/CHANGELOG.md): `LandingLayout` and `LandingSection` leave a 4px inset inside their scroll viewports, so the box's outer halo and a row's focus ring are no longer clipped at the sides.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.64/packages/ui/CHANGELOG.md): `MenuPreviewLayout` takes `previewWidth: "remaining"` for a menu whose width is set from outside: the preview takes the width the options leave and is hidden below 10rem, so it never paints past the menu. The default, `"fixed"`, keeps the fixed-width pane.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.64/packages/ui/CHANGELOG.md): Expose controlled browser time for component and integration tests.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.64/packages/ui/CHANGELOG.md): `textMarkBoxClass` draws a text mark as a box over painted text, such as a PDF page, where no text decoration reaches the words: the hue, wash and ring of `textMarkClass`, with a line variant as the box's edge.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.64/packages/ui/CHANGELOG.md): `useInspectorPaneWidth` takes its storage through an injected `persistence` option (`InspectorPaneWidthPersistence`); `parsePersistedPaneWidth`, `readStoredWidth` and `writeStoredWidth` are removed.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.64/packages/cli/CHANGELOG.md): Document uploads read their PUT timeout from the shared upload contract, so the CLI and the API agree on how long an upload may run and still be finalized.
- [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.64/packages/workspace-ui/CHANGELOG.md): Add `@stll/workspace-ui/feature-previews`: static product scenes (matters, documents, research, billing, contacts, time tracking) composed from the app's own components, for marketing pages, menus and slides. Each scene takes its interface labels and a formatting locale. Add `@stll/workspace-ui/task-status`, the glyph and colour of each task status.
