# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/ai-catalog](https://github.com/stella/stella/blob/v0.9.58/packages/ai-catalog/CHANGELOG.md): Refresh upstream model rates and request capabilities.
- [@stll/agent-input](https://github.com/stella/stella/blob/v0.9.58/packages/agent-input/CHANGELOG.md): Closed enum near-miss suggestions count Unicode scalar values, including astral characters.
- [@stll/agent-input](https://github.com/stella/stella/blob/v0.9.58/packages/agent-input/CHANGELOG.md): Depends on the published @stll/time release.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.58/packages/cli/CHANGELOG.md): Case-law search automatically tries partial matching when a question has no full matches, ranks partial hits by term coverage, and exposes match classifications and warnings in API, MCP, CLI and web results.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.58/packages/cli/CHANGELOG.md), [@stll/mcp-kit](https://github.com/stella/stella/blob/v0.9.58/packages/mcp-kit/CHANGELOG.md): Keep published clients independent from private workspace packages while preserving supported-version requests.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.58/packages/cli/CHANGELOG.md), [@stll/mcp-kit](https://github.com/stella/stella/blob/v0.9.58/packages/mcp-kit/CHANGELOG.md): Export `package.json` so consumers can read the installed package version.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.58/packages/ui/CHANGELOG.md): The floating outline opens from its tick strip (hover, focus or tap) and no longer draws a toggle button; Escape closes it and returns focus to the tick.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.58/packages/cli/CHANGELOG.md), [@stll/mcp-kit](https://github.com/stella/stella/blob/v0.9.58/packages/mcp-kit/CHANGELOG.md): Require supported local client versions, identify CLI and MCP kit requests, cache CLI update metadata, and turn incompatibilities into actionable update errors. Keep CLI version tests on the server metadata contract and scope the local-client CORS header to MCP transport requests.
- [@stll/mcp-kit](https://github.com/stella/stella/blob/v0.9.58/packages/mcp-kit/CHANGELOG.md): Bound tool name suggestions to the tool name length.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.58/packages/ui/CHANGELOG.md): `Prose` sets an 80-character measure for narrative text.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.58/packages/ui/CHANGELOG.md): `Prose` accepts `tone` and `size` variants for muted and small narrative copy.
