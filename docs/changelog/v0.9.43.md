# Maintenance release

Stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.43/packages/cli/CHANGELOG.md): The generated agent skill describes input-only union fields: the discriminator values, each variant's keys and one minimal `--input` example.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.43/packages/cli/CHANGELOG.md): Add global timer capabilities and remove per-entry timer capabilities.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.43/packages/cli/CHANGELOG.md): Add invoice line commands.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.43/packages/cli/CHANGELOG.md): Accept the longer continuation cursor legislation search now returns.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.43/packages/cli/CHANGELOG.md): `save_playbook` documents when `scope.perspective` is set: only for a buyer, seller, or neutral side; a recipient, controller, or customer omits it.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.43/packages/cli/CHANGELOG.md): Add administrative timer listing and completion capabilities.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.43/packages/cli/CHANGELOG.md): Add VAT rate management capabilities with validity dates.
