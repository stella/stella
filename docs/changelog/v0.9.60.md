# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/calculations](https://github.com/stella/stella/blob/v0.9.60/packages/calculations/CHANGELOG.md): Column calculations now report non-finite inputs and overflowing reductions as unsupported instead of returning non-finite results.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.60/packages/ui/CHANGELOG.md): Scroll areas capped with a max height now scroll inside the cap instead of growing past it.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.60/packages/ui/CHANGELOG.md): `Loader` draws a plain spinner for busy controls and rows; `LoaderState` keeps the Stella mark for empty regions.
