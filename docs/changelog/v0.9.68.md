# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/ui](https://github.com/stella/stella/blob/v0.9.68/packages/ui/CHANGELOG.md): `DetailsGrid` keeps one column's width inside a popover or another box sized by its content.
- [@stll/fetch](https://github.com/stella/stella/blob/v0.9.68/packages/fetch/CHANGELOG.md): First release: `fetchWithTimeout` with a required headers or idle timeout, `createFetchWithTimeout`, `isConnectionFailure`, and the robots-aware polite fetch in `@stll/fetch/publisher`.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.68/packages/ui/CHANGELOG.md): `InlineRenameInput` sets `enterKeyHint="done"` by default, so touch keyboards label Enter as the commit key; callers can still override it.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.68/packages/ui/CHANGELOG.md): `KanbanCardShell` takes `selected` and `onSelectionClick`: a selected card draws the selection ring, and a Cmd/Ctrl- or Shift-click reports its modifiers instead of opening the card. `registerKanbanCardDrag` takes `getDragPreview` to draw a custom preview, such as a stack for several cards. Cards and column headers carry `data-kanban-card` and `data-kanban-column-header` markers.
- [@stll/scan-engine](https://github.com/stella/stella/blob/v0.9.68/packages/scan-engine/CHANGELOG.md): First release: the WebAssembly scan cleanup engine (`createScanEngine`), its types, and the per-page review state machine (`@stll/scan-engine/review`).
- [@stll/text-normalize](https://github.com/stella/stella/blob/v0.9.68/packages/text-normalize/CHANGELOG.md): Add `createSearchQueryMatcher` and `filterBySearchQuery` at `@stll/text-normalize/search-query-matcher`: the client-side match for user-typed queries. Both sides fold through `foldSearchMatchText`, so case, accents, `ß`/`ł`/`ø`, ligatures and Arabic variants are ignored the same way in every locale.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.68/packages/ui/CHANGELOG.md): Remove `useComboboxFilter`. Its `Intl.Collator` match compares equal-length windows (`strasse` never finds `Straße`) and depends on the runtime locale; pass a `filter` built on `createSearchQueryMatcher` from `@stll/text-normalize/search-query-matcher` instead.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.68/packages/ui/CHANGELOG.md): `@stll/ui/icons` no longer re-exports `ClipboardPasteIcon`, `Loader2Icon`, `LoaderIcon`, `NetworkIcon` and `PresentationIcon`, which no source imports.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.68/packages/ui/CHANGELOG.md): The outline rail renders only the rows whose entry, active state or hover state changed, keeps an unchanged entry's row when the items are rebuilt, and keeps a branch the reader closed closed across such a rebuild.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.68/packages/cli/CHANGELOG.md): The case-law search `sort` option's description now says that `newest` lists undated decisions last instead of leaving them out.
- [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.68/packages/workspace-ui/CHANGELOG.md): Sort chips name their direction with the caller's wording for the property's sort kind. `SortableProperty` takes a required `sortKind` and `SortChipsLabels` a total `directions` record, both typed by the new `@stll/workspace-ui/column-sort` entry (`ColumnSortKind`, `SortDirection`, `SortDirectionLabels`). `sortDirectionHint` and its hard-coded `A→Z` / `1→9` / arrow hints are removed.
- [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.68/packages/workspace-ui/CHANGELOG.md): Add `@stll/workspace-ui/formatting` with `WorkspaceUiFormattingProvider`. Field values and column calculations format numbers, money and dates in the locale it supplies instead of `use-intl`'s locale, so a host can keep the UI language and the regional format apart. Rendering them outside the provider throws.
