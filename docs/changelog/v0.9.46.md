# Maintenance release

Stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.46/packages/cli/CHANGELOG.md): Handle structured action refusal codes.
- [@stll/business-registries](https://github.com/stella/stella/blob/v0.9.46/packages/business-registries/CHANGELOG.md): Add an opt-in request observation hook.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.46/packages/ui/CHANGELOG.md): Remove the unused sortable Kanban layer: `KanbanSortableBoard`, `useKanbanSortable`, `KanbanDragHandle` and the `sortable` prop of `KanbanVirtualCell` are no longer exported.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.46/packages/ui/CHANGELOG.md): Add `CopyButton`, which confirms a copy in place; semantic `NewChatIcon` and `AddCommentIcon`; and a centered slot in `ComposerStatusRow`.
