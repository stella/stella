# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.85/packages/cli/CHANGELOG.md): Case-law coverage reports publisher slice counts, stored and text counts, and conservative completeness verdicts for each source and country.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.85/packages/cli/CHANGELOG.md): Include procedural review evidence alongside case-law citation results.
- [@stll/chat](https://github.com/stella/stella/blob/v0.9.85/packages/chat/CHANGELOG.md): Export `finishedChatRunResponse` from `@stll/chat/durable-transport`: the stream that only ends a run, which a client reads when it follows the turn in the stored thread instead of its live stream.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.85/packages/cli/CHANGELOG.md): Enforce the shared 500-character search query limit in contact list and search capability schemas.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.85/packages/cli/CHANGELOG.md): Document citation polarity evidence and the cited opinion part in case-law citation reads.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.85/packages/cli/CHANGELOG.md): Apply the existing 500-character search query limit to clause searches in the generated capability contract.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.85/packages/ui/CHANGELOG.md): Let open Collapsible content, hanging controls, and focus rings extend beyond the panel. Use an opacity-only opening reveal with immediate layout changes and closing, preserving hidden-until-found and reduced-motion behavior.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.85/packages/ui/CHANGELOG.md): Add a composer appearance to Textarea that shares the large composer editor typography and geometry without field chrome.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.85/packages/cli/CHANGELOG.md): `dictation transcribe` accepts the direct ElevenLabs Scribe v3 model id.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.85/packages/cli/CHANGELOG.md): `dictation transcribe` accepts the refreshed transcription model ids.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.85/packages/ui/CHANGELOG.md): Add HighlightedTextarea with shared highlighted text layers and native editing, synchronized scrolling, and inherited direction.
- [@stll/anonymize-chat](https://github.com/stella/stella/blob/v0.9.85/packages/anonymize-chat/CHANGELOG.md): Add the `local_run_anonymized_refusal` transport code for an anonymized send to a turn on the member's computer, and `isChatTransportErrorCode`. Every transport refusal code now reads as one the member can send past without anonymization.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.85/packages/ui/CHANGELOG.md), [@stll/cli](https://github.com/stella/stella/blob/v0.9.85/packages/cli/CHANGELOG.md): Add `OutcomeScreen` (`@stll/ui/outcome-screen`), the one screen a finished flow shows. The CLI's browser sign-in page is now rendered from it.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.85/packages/ui/CHANGELOG.md), [@stll/cli](https://github.com/stella/stella/blob/v0.9.85/packages/cli/CHANGELOG.md): `OutcomeScreen` lists what a flow connected (`details`) and can offer a command to run (`command`). The CLI's browser sign-in page names the signed-in account and organization, and a failed sign-in shows `stella auth login` to try again.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.85/packages/cli/CHANGELOG.md): Generate the packaged capability manifests from API sources during CLI builds and package preparation.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.85/packages/ui/CHANGELOG.md): Add a controlled cell appearance to Checkbox that owns row-label reveal, first-line alignment, and the full selection hit area while preserving the default appearance.
- [@stll/ai-catalog](https://github.com/stella/stella/blob/v0.9.85/packages/ai-catalog/CHANGELOG.md): Transcription models name their route (OpenRouter, or straight to ElevenLabs under the provider's model id), add Scribe v3, and `transcriptionEndpointFor` and `defaultTranscriptionModelId` take what the deployment serves.
- [@stll/ai-catalog](https://github.com/stella/stella/blob/v0.9.85/packages/ai-catalog/CHANGELOG.md): Transcription models now list availability on the global endpoint and a provider name, with refreshed prices, US availability and new zero-retention models; `transcriptionEndpointFor` picks the endpoint that serves a model for an organization.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.85/packages/cli/CHANGELOG.md): Require `expectedUpdatedAt` when replacing a workflow definition with `flows.update`. Read the definition with `flows.get` and send its `updatedAt` value with the edited fields. A stale version returns `version_conflict` without changing the workflow; read the current definition and reconcile the intended changes before submitting again. Successful updates return the new `updatedAt` value.
