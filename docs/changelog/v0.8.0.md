# Bilingual documents

## stella now translates a contract into a two-column bilingual document.

Open any DOCX and ask for a bilingual version. stella lays the original and the translation side by side, paragraph for paragraph, keeps the clause numbering, headings, and tables where they were, and uses the defined terms consistently through the whole document. Pick the target language from a list you can type into; stella suggests the language the rest of the matter is written in, then the one you used last.
