# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.52/packages/cli/CHANGELOG.md): Add `case-law open` to open a case-law decision, optionally at a range of paragraphs.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.52/packages/cli/CHANGELOG.md): Expose decision passage headings, publisher labels, positions, and text source.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.52/packages/ui/CHANGELOG.md): Add shared chart palette tokens for theme-aware generated views.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.52/packages/cli/CHANGELOG.md): Declare legal list availability in generated capability contracts.
- [@stll/auth-model](https://github.com/stella/stella/blob/v0.9.52/packages/auth-model/CHANGELOG.md): Add the shared sign-in recovery constants.
