# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.79/packages/cli/CHANGELOG.md): `properties create` and `properties batch-create` accept `toolType: "ai-model"` for a money column, and `properties prompt-suggest` accepts the `money` content type. An AI money column requires the `table-analysis` feature.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.79/packages/cli/CHANGELOG.md): `fields cell-metadata-update` accepts `overrideReason`: why a person replaced the value a run produced in a cell. It is refused with `cell_override_absent` on a cell that holds no such replacement.
- [@stll/agent-input](https://github.com/stella/stella/blob/v0.9.79/packages/agent-input/CHANGELOG.md), [@stll/business-registries](https://github.com/stella/stella/blob/v0.9.79/packages/business-registries/CHANGELOG.md), [@stll/chat](https://github.com/stella/stella/blob/v0.9.79/packages/chat/CHANGELOG.md), [@stll/cli](https://github.com/stella/stella/blob/v0.9.79/packages/cli/CHANGELOG.md), [@stll/template-conditions](https://github.com/stella/stella/blob/v0.9.79/packages/template-conditions/CHANGELOG.md), [@stll/ui](https://github.com/stella/stella/blob/v0.9.79/packages/ui/CHANGELOG.md), [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.79/packages/workspace-ui/CHANGELOG.md): Update compatible runtime dependencies: `@stll/time` 0.4.2, `temporal-polyfill` 1.0.6, `lucide-react` 1.65.0, Tiptap 3.32.1 and the MCP client 2.4.0.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.79/packages/cli/CHANGELOG.md): `stella case-law read --query` says which words a query with no match could not find together, and which query to try next. It still returns no paragraph unless one holds every word.
- [@stll/fetch](https://github.com/stella/stella/blob/v0.9.79/packages/fetch/CHANGELOG.md): A total deadline is now the only limit on a request: `fetchWithTimeout` turns off Bun's idle limit, which cut a response that stayed silent for about five minutes whatever the deadline allowed. A `headers` policy keeps it.
- [@stll/html](https://github.com/stella/stella/blob/v0.9.79/packages/html/CHANGELOG.md): Use the `domhandler` 5 that parse5's htmlparser2 tree adapter and Cheerio build their trees with, so the exported node types, guards and constructors describe the nodes `load` returns.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.79/packages/ui/CHANGELOG.md): `InputGroupAddon` no longer focuses its input when a press lands inside a menu or popover opened from the addon.
- [@stll/money](https://github.com/stella/stella/blob/v0.9.79/packages/money/CHANGELOG.md): Add locale decimal input parsing and exact redisplay formatters, with branded `LocaleInputText` values that keep canonical stored decimals out of locale-validated form fields: such text comes only from the formatters, from an input element (`localeInputText`) or as `EMPTY_LOCALE_INPUT_TEXT`. Parsing accepts locale separators or an unambiguous dot or comma decimal, and reports a typed `LocaleAmountParseError` instead of guessing when text allows two readings.
- [@stll/money](https://github.com/stella/stella/blob/v0.9.79/packages/money/CHANGELOG.md): Add `toMajorUnitsText`: a stored minor-unit amount as exact major-unit decimal text (`123456 EUR` is `"1234.56"`), for machine readers such as prompts and exports.
- [@stll/ai-catalog](https://github.com/stella/stella/blob/v0.9.79/packages/ai-catalog/CHANGELOG.md): Offer GPT-6.1 Terra. The offered model id types and option lists change with it, so code that matches them exhaustively has to handle the new id.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.79/packages/cli/CHANGELOG.md): `stella case-law search`, `stella legislation search` and `stella legislation read` results carry the publisher link once, as `source_url`. The duplicate `sourceUrl` field is gone.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.79/packages/cli/CHANGELOG.md): `stella case-law resolve` returns a decision's identity and whether its text can be read, not the text. Read the text with `stella case-law read`.
- [@stll/scan-engine](https://github.com/stella/stella/blob/v0.9.79/packages/scan-engine/CHANGELOG.md): Rebuild the WebAssembly engine with wasm-bindgen 0.2.130.
- [@stll/text-normalize](https://github.com/stella/stella/blob/v0.9.79/packages/text-normalize/CHANGELOG.md): `@stll/text-normalize` reads letter-spaced text in one place: `collapseLetterSpacing`, `documentWordCounts`, `isLetterSpacedEmphasis`, `letterSpacingJoins`, `letterGapCounts` and `joinWordSeams` are added, and `collapseSpacedLetters` is now that reading with spaces squeezed. A short spaced word beside a spaced word reads as a word, a row of one-letter words a sentence writes stays apart, and a no-break space separates words. `spacedLetterRunRegex` is removed from `@stll/text-normalize`; use `letterSpacingJoins` for the gaps a fold removes.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.79/packages/ui/CHANGELOG.md): `Accordion` now keeps closed panels as `hidden="until-found"` by default, so find-in-page reaches their content (pass `hiddenUntilFound={false}` to unmount them), and `AccordionTrigger` gains a `trailing` slot for status text before its chevron.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.79/packages/ui/CHANGELOG.md): See package changelog for details.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.79/packages/ui/CHANGELOG.md), [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.79/packages/workspace-ui/CHANGELOG.md): Corner radii name a scale step: bare `rounded` is now `rounded-sm`, and the checkbox, segmented toggle and input-group keycap use scale steps instead of pixel radii. `--radius` is 0.5rem. Light text is neutral-900, dark muted text neutral-400, and sidebar text is stronger in both themes.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.79/packages/ui/CHANGELOG.md): View toolbars never grow past their container on a small screen, so controls past the edge are scrolled to rather than clipped. Sortable table heads stay inside the table's edge.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.79/packages/cli/CHANGELOG.md): Reading case-law citations accepts `detail: compact` for short passages and `passage_query` to keep only citations whose citing paragraph holds given words.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.79/packages/cli/CHANGELOG.md): `case-law search` accepts `--docket-registers` and `--senate` to filter Czech and Slovak decisions by their docket.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.79/packages/cli/CHANGELOG.md): `case-law search` and `case-law read` accept `--preferred-language` to return a decision in that language where a version exists.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.79/packages/cli/CHANGELOG.md): The case-law search `provision` description no longer offers EU provisions, which have no recorded links yet; name them in the query instead.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.79/packages/cli/CHANGELOG.md): `case-law read` accepts `--resume-after` to continue a query's matches and `--section court_reasoning` to restrict them, reporting when the boundary was not found.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.79/packages/cli/CHANGELOG.md): `search_case_law` returns the phrasings that finished when others run out of time, and the returned cursor runs those phrasings again.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.79/packages/cli/CHANGELOG.md): `search_case_law` reports a total only when the call names facets, for a single phrasing.
- [@stll/chat](https://github.com/stella/stella/blob/v0.9.79/packages/chat/CHANGELOG.md): `ChatLink` accepts `urlLabel: "written"` to keep a link's own text when that text is a URL, instead of showing the bare host.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.79/packages/cli/CHANGELOG.md): `organization-settings get` also returns `localRunMaxApprovalMode`, the most a chat turn run on a member's computer may do without asking.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.79/packages/cli/CHANGELOG.md): `search_case_law` and `search_legislation` can answer `status: "running"` with `continuation_token` when a search outlives its response deadline, instead of timing out. Calling again with the token collects the answer. Two new error codes: `continuation_expired` and `public_read_unfinished`.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.79/packages/cli/CHANGELOG.md): Adds `guidance search` and `guidance read` for regulator guidance served by stella.
