# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/fetch](https://github.com/stella/stella/blob/v0.9.71/packages/fetch/CHANGELOG.md): Hand a request with a numeric deadline straight to the transport and return its response unchanged, bounded by a total deadline on the request signal.
- [@stll/fetch](https://github.com/stella/stella/blob/v0.9.71/packages/fetch/CHANGELOG.md): Apply total request deadlines while response bodies are being consumed.
- [@stll/fetch](https://github.com/stella/stella/blob/v0.9.71/packages/fetch/CHANGELOG.md): Return the transport's response unchanged for an explicit `total` deadline too, bounded through the request signal like the numeric form.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.71/packages/cli/CHANGELOG.md): Add personal account export request, status, and authenticated download-link commands with explicit account-export OAuth consent.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.71/packages/cli/CHANGELOG.md): Describe disabled analysis generation and source restrictions with distinct availability codes.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.71/packages/ui/CHANGELOG.md): Add `@stll/ui/badge` (status and type labels in the list status tones plus `info`, `xs`/`sm`, optional dot) and `@stll/ui/truncated-text` (ellipsis text that shows its full content in a tooltip only when it is actually cut, with a tap popover on touch). `TooltipProvider` now opens tooltips after 300ms by default and keeps Base UI's warm window between adjacent triggers.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.71/packages/ui/CHANGELOG.md): Ship the coss ui license notice with the package.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.71/packages/ui/CHANGELOG.md): See package changelog for details.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.71/packages/ui/CHANGELOG.md): Install lucide-react 1.61.0.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.71/packages/ui/CHANGELOG.md): Add React Native renderers beside the web components a phone needs: `Button`, `Text` (new, a role-based text primitive on both platforms), `Loader`, `Input`, `Textarea`, `Switch`, `Sheet`, `Separator`, `MatterIcon` and `StellaWordmarkLatin`. Each export resolves to its native renderer under the `react-native` condition and to the web renderer everywhere else, and both read one shared contract (`<component>.shared.ts`: props, variant tokens, sizes). React Native, uniwind, react-native-svg and lucide-react-native are optional peer dependencies that only the native renderers import.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.71/packages/ui/CHANGELOG.md): Add `scroll-edge-fade`: a mask that fades a horizontal scroller's edges while content continues past them. `HorizontalScroller` uses it in place of its background-coloured gradient overlays, so its fade works over any background.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.71/packages/ui/CHANGELOG.md): See package changelog for details.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.71/packages/ui/CHANGELOG.md): Show sidebar menu actions and inspector resize grips on coarse-pointer devices.
