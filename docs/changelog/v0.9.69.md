# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/text-normalize](https://github.com/stella/stella/blob/v0.9.69/packages/text-normalize/CHANGELOG.md): Keep every item when the search query folds to an empty key, including items without searchable fields.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.69/packages/cli/CHANGELOG.md): Preserve retry hints and advisory delays for concurrent public-law reads.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.69/packages/ui/CHANGELOG.md): Settled toasts take their own dismissal timing: a loading toast updated to success, error or cancelled no longer keeps the loading toast's infinite lifetime, unless the update names a timeout itself.
