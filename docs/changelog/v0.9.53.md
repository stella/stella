# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.53/packages/cli/CHANGELOG.md): Connect to the advanced MCP connection (`/mcp/advanced`), which keeps generic capability commands and tools from connected external MCP servers; the default MCP connection now lists only purpose-built tools.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.53/packages/cli/CHANGELOG.md): Case-law analysis generation answers a failed run with a typed code and whose key it used, and accepts `retry` to run again.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.53/packages/cli/CHANGELOG.md): Case-law analysis generation describes how long a failed run answers before a plain call starts a new one.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.53/packages/cli/CHANGELOG.md): Always include `textVersion` in case-law decision reads, and report incomplete docket identifiers with an `incomplete_identifier` status and their `missing` components.
- [@stll/text-normalize](https://github.com/stella/stella/blob/v0.9.53/packages/text-normalize/CHANGELOG.md), [@stll/anonymize-chat](https://github.com/stella/stella/blob/v0.9.53/packages/anonymize-chat/CHANGELOG.md), [@stll/business-registries](https://github.com/stella/stella/blob/v0.9.53/packages/business-registries/CHANGELOG.md): Centralize Unicode normalization and mark stripping in `@stll/text-normalize` and use the shared behavior in dependent packages.
