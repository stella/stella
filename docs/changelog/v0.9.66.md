# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.66/packages/cli/CHANGELOG.md): Recognize the `action_feature_disabled` admission refusal, returned while an operator has turned the requested feature off, and exit with the feature-disabled code.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.66/packages/cli/CHANGELOG.md): Add `stella capability` commands for document redline suggestions (`docx-suggestions list`, `resolve`, `revert`), assistant memory (`memories list`, `create`, `update`) and notifications (`notifications list`, `read-state-update`).
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.66/packages/cli/CHANGELOG.md), [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.66/packages/workspace-ui/CHANGELOG.md): Paginate filesystem tree reads and expose bounded text previews in entity lists.
- [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.66/packages/workspace-ui/CHANGELOG.md): Allow hosts to provide typed content for workspace feature previews while retaining the default scenes.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.66/packages/cli/CHANGELOG.md): Add tax ID, VAT-payer status and invoice language to contacts, a language to invoices, and a command that adds a country's VAT rates from a preset.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.66/packages/cli/CHANGELOG.md): Add the Polish KSeF FA(3) e-invoice format to invoice export.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.66/packages/ui/CHANGELOG.md): `LandingLayout` and `LandingSection` leave a 4px inset inside their scroll viewports, so the box's outer halo and a row's focus ring are no longer clipped at the sides.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.66/packages/ui/CHANGELOG.md): `MenuPreviewLayout` takes `previewWidth: "remaining"` for a menu whose width is set from outside: the preview takes the width the options leave and is hidden below 10rem, so it never paints past the menu. The default, `"fixed"`, keeps the fixed-width pane.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.66/packages/ui/CHANGELOG.md): Expose controlled browser time for component and integration tests.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.66/packages/ui/CHANGELOG.md): `textMarkBoxClass` draws a text mark as a box over painted text, such as a PDF page, where no text decoration reaches the words: the hue, wash and ring of `textMarkClass`, with a line variant as the box's edge.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.66/packages/ui/CHANGELOG.md): `useInspectorPaneWidth` takes its storage through an injected `persistence` option (`InspectorPaneWidthPersistence`); `parsePersistedPaneWidth`, `readStoredWidth` and `writeStoredWidth` are removed.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.66/packages/cli/CHANGELOG.md): Document uploads read their PUT timeout from the shared upload contract, so the CLI and the API agree on how long an upload may run and still be finalized.
- [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.66/packages/workspace-ui/CHANGELOG.md): Add `@stll/workspace-ui/feature-previews`: static product scenes (matters, documents, research, billing, contacts, time tracking) composed from the app's own components, for marketing pages, menus and slides. Each scene takes its interface labels and a formatting locale. Add `@stll/workspace-ui/task-status`, the glyph and colour of each task status.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.66/packages/cli/CHANGELOG.md): `stella case-law search` accepts Slovakia, Hungary and the EU, and `stella legislation search` accepts Slovakia.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.66/packages/cli/CHANGELOG.md): Add the folder-from-selection capability: create a folder and move a selection into it atomically.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.66/packages/cli/CHANGELOG.md): Invoice line commands accept an exemption basis, the legal provision printed for an exempt or non-VAT-payer line, and the VAT rate preset command accepts Poland.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.66/packages/ui/CHANGELOG.md): `Steps` renders an ordered sequence as a semantic list, numbered by the list itself.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.66/packages/cli/CHANGELOG.md): Update the generated company-registry lookup contract for verified KRS name searches.
- [@stll/agent-input](https://github.com/stella/stella/blob/v0.9.66/packages/agent-input/CHANGELOG.md), [@stll/cli](https://github.com/stella/stella/blob/v0.9.66/packages/cli/CHANGELOG.md): Add strict whole-token numeric parsers for machine input. Reject malformed CLI pagination tokens while preserving localized tool-value normalization.
- [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.66/packages/workspace-ui/CHANGELOG.md): `ResponsiveActionToolbar` wraps its slots instead of scrolling them behind a hidden scrollbar, and the action slot aligns to the inline end by itself.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.66/packages/cli/CHANGELOG.md): Finalizing a VAT invoice in a currency other than the seller country's VAT currency records the official exchange rate for its tax point and states the VAT in that currency.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.66/packages/cli/CHANGELOG.md): Invoice export offers a Peppol BIS Billing 3.0 format for Slovak sellers.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.66/packages/cli/CHANGELOG.md): `stella capability list` takes `--query <text>` to search capabilities by id, title and description.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.66/packages/cli/CHANGELOG.md): Read capability input schemas in their standard JSON Schema form: string literal unions stay enum flags whether or not each value states its type, file inputs state their size cap as `x-maxBytes`, and inputs list only the defaults the API applies.
