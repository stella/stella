# Maintenance release

## Case-law upkeep runs steadier behind the scenes.

The citation-authority ranking signal now refreshes shortly after the
ingestion service starts instead of waiting a full interval, so ranking
stays fresh across restarts. The corpus search index selects its
backfill work with an efficient query plan, keeping large corpora
indexing steadily, and document-archive writes that fail now log their
cause. Halted ingestion cycles count their completed pages as progress.
