# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.86/packages/cli/CHANGELOG.md): Statute `amendedBy` and `pendingChanges` show an instruction the publisher restates under several links once, naming every link in `duplicatePublisherIds`. Provision reads document `governingText`, `governingTextTruncated` and reading an annex by its number.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.86/packages/cli/CHANGELOG.md): `search_case_law` says which query words each decision holds, how many decisions hold each word when few hold them all, and gives a cursor that runs a phrasing again when its partial matches went unread.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.86/packages/ui/CHANGELOG.md): Move inspector width persistence to the host application. Supply `initialWidth` for the server snapshot and `onWidthChange` to persist completed resizes; the hook no longer accepts `storageKey` or reads browser storage. Remove the browser-storage width helpers.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.86/packages/cli/CHANGELOG.md): Email an issued invoice as a secure link with `invoices sends-create`, list its sends with `invoices sends-list` and withdraw a link with `invoices sends-revoke`. Seller profiles take an `email` that receives the replies.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.86/packages/cli/CHANGELOG.md): Sending invoice links requires the organization's invoice-links invitation grant and time-billing access. History and revocation remain available through normal invoice access without an invitation or personal enrolment.
- [@stll/ai-catalog](https://github.com/stella/stella/blob/v0.9.86/packages/ai-catalog/CHANGELOG.md): Offer GPT-6.2 Astra and GPT-6.2 Sol. The offered model id types and option lists change with them, so code that matches them exhaustively has to handle the new ids.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.86/packages/cli/CHANGELOG.md): `read_statute_provisions` and `read_provision_history` return `governingText` beside a subdivision's text: the lead-in and closing wording of every unit it is nested in, so a letter is never read without the sentence that qualifies it.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.86/packages/cli/CHANGELOG.md): `resolve_case_law_decision` answers a decision it does not find with what the reconciled publisher listings say about it.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.86/packages/cli/CHANGELOG.md): `save_contact` describes its registration, tax and VAT fields as a business's numbers.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.86/packages/cli/CHANGELOG.md): Add standalone native installation, checksum-verified self updates, and installation diagnostics. Check the server protocol and minimum CLI version before API operations, using a fresh cached contract when available.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.86/packages/cli/CHANGELOG.md): Statute reads accept an annex by its number in any spelling (`priloha_3`, `příloha č. 3`), `read_statute` keeps every annex in a bounded outline, and a missing annex lists the annex anchors the consolidation carries.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.86/packages/ui/CHANGELOG.md): Add React Native renderers beside the web components a phone needs: `Button`, `Text` (new, a role-based text primitive on both platforms), `Loader`, `Input`, `Textarea`, `Switch`, `Sheet`, `Separator`, `MatterIcon` and `StellaWordmarkLatin`. Each export resolves to its native renderer under the `react-native` condition and to the web renderer everywhere else, and both read one shared contract (`<component>.shared.ts`: props, variant tokens, sizes). React Native, uniwind, react-native-svg and lucide-react-native are optional peer dependencies that only the native renderers import.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.86/packages/ui/CHANGELOG.md), [@stll/workspace-ui](https://github.com/stella/stella/blob/v0.9.86/packages/workspace-ui/CHANGELOG.md): `WorkspaceShell` takes an optional `skipToContentLabel`. When set, the shell renders a visually hidden skip link as its first tab stop that moves focus to the main region. `WorkspaceFrame` passes it through in the `host-responsive` composition.
