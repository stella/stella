# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.54/packages/cli/CHANGELOG.md): `read_case_law_citations` filters by doctrine and polarity; a doctrine filter on a surface without doctrine is refused instead of returning an empty page.
- [@stll/chat](https://github.com/stella/stella/blob/v0.9.54/packages/chat/CHANGELOG.md): Remove the unused shared composer shell and action component while retaining composer action-mode resolution for host-owned controls.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.54/packages/cli/CHANGELOG.md): Resolve EU decisions by ECLI and include available decision languages.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.54/packages/cli/CHANGELOG.md): Document EU-law provision filters for case-law search.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.54/packages/cli/CHANGELOG.md): Add an as-of date to legislation search and return the matched consolidation validity window.
- [@stll/mcp-kit](https://github.com/stella/stella/blob/v0.9.54/packages/mcp-kit/CHANGELOG.md): Name suggestions compute their distances without a native dependency.
