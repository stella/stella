# Maintenance release

Stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.40/packages/cli/CHANGELOG.md): Capability commands read the capability output from the `result` envelope the server returns, so pages still render as tables with their resume cursor.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.40/packages/cli/CHANGELOG.md): Command help describes the lenient input readings: page sizes clamp, range dates accept a bare year or month, and statute ELIs accept short spellings.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.40/packages/cli/CHANGELOG.md): Command help no longer points at tools a surface does not expose.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.40/packages/cli/CHANGELOG.md): Add correspondence read, handling, and sender-approval capabilities.
- [@stll/business-registries](https://github.com/stella/stella/blob/v0.9.40/packages/business-registries/CHANGELOG.md), [@stll/cli](https://github.com/stella/stella/blob/v0.9.40/packages/cli/CHANGELOG.md): Add entity checks: screen a company by IČO or a person by name and birth date against the Czech insolvency register (ISIR). Each check answers clear, found (with typed findings), unavailable, or not-covered; a source error, timeout, outage page, or unparseable answer is never reported as clear. The CLI gains `contact check-counterparty`.
- [@stll/business-registries](https://github.com/stella/stella/blob/v0.9.40/packages/business-registries/CHANGELOG.md), [@stll/cli](https://github.com/stella/stella/blob/v0.9.40/packages/cli/CHANGELOG.md): Add the `cz-vat-reliability` entity check: the Czech VAT register's unreliable-payer status and published bank accounts for a DIČ. An IČO is sent as `CZ` + IČO and the result marks the DIČ as derived. A DIČ the register does not hold is reported as `not-registered`, never as clear.
- [@stll/business-registries](https://github.com/stella/stella/blob/v0.9.40/packages/business-registries/CHANGELOG.md), [@stll/cli](https://github.com/stella/stella/blob/v0.9.40/packages/cli/CHANGELOG.md): Add `orsr.lookupFullRecordByIco` (history, filed documents, related persons) and the opt-in `detail: "full"` registry lookup.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.40/packages/ui/CHANGELOG.md): Add `--ease-spring` and `--ease-smooth` easing tokens (`ease-spring`, `ease-smooth` utilities). The toast entry uses `--ease-smooth`, the button loading spinner fades and scales in, and both respect `prefers-reduced-motion`.
