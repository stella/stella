# Maintenance release

Stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.39/packages/cli/CHANGELOG.md): `catalogue install` requires the skill-create permission instead of organization settings access, so a member can install a catalogue skill at private scope. Team scope still requires an owner or admin.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.39/packages/cli/CHANGELOG.md): `skills seed` is gone: a member's default skills are installed when the membership is created.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.39/packages/cli/CHANGELOG.md): The legislation read help states that full text is returned only when the parsed structure is missing or unusable.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.39/packages/ui/CHANGELOG.md): Component hover, focus and selection colours, borders and shadows change instantly; remaining component motion animates transform and opacity only.
- [@stll/business-registries](https://github.com/stella/stella/blob/v0.9.39/packages/business-registries/CHANGELOG.md), [@stll/cli](https://github.com/stella/stella/blob/v0.9.39/packages/cli/CHANGELOG.md): Add the Slovak legal-entity register (RPO) as `@stll/business-registries/rpo` and as the `rpo` registry.
