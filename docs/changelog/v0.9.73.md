# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.73/packages/cli/CHANGELOG.md): Expose import provenance fields and the batch contact import capability.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.73/packages/cli/CHANGELOG.md): `matters.members.list` lists a matter's members, with each user's id, name, email and image, to an access token with `stella:read`. Tasks take assignees with `stella:matters_write`.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.73/packages/ui/CHANGELOG.md): `DayCalendar` blocks shorter than one label line (`DAY_CALENDAR_ONE_LINE_BLOCK_MIN_PX`) draw their surface only; their accessible label and tooltip still carry them.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.73/packages/ui/CHANGELOG.md): `DayCalendar` entries take a `suggestion` state: a lighter, dashed block rendered as a button that calls the block's `onActivate` without starting a range selection. Any block can carry a `tooltip`.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.73/packages/ui/CHANGELOG.md): A scroll area's viewport is the containing block of what is positioned inside it, so an absolutely positioned descendant, such as a visually hidden label, stays inside the scroll instead of giving an ancestor a scrollbar of its own.
