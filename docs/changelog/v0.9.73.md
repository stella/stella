# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.73/packages/cli/CHANGELOG.md): Activity log entries for a resource type this version does not recognise report their recorded changes as withheld instead of empty.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.73/packages/cli/CHANGELOG.md): `stella auth login` signs in as the client the server publishes for the CLI and no longer registers a client of its own. A server whose authorization server cannot identify the CLI that way (no https issuer, or no client metadata document support) is refused; use an API key there.
- [@stll/auth-model](https://github.com/stella/stella/blob/v0.9.73/packages/auth-model/CHANGELOG.md), [@stll/cli](https://github.com/stella/stella/blob/v0.9.73/packages/cli/CHANGELOG.md): Allow organization owners and admins to change an existing organization's slug through generated capabilities, with an opaque identifier option and shared slug validation.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.73/packages/ui/CHANGELOG.md): See package changelog for details.
