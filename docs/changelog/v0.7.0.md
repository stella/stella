# Playbooks

## Turn your contract standards into reusable review checklists

Define acceptable, fallback, and unacceptable positions. Add preferred language
and negotiation guidance, or set exact rules for measurable thresholds.

You can run a playbook across a table of documents or upload a file for direct
review. Compare documents against references, apply a playbook, or combine both.

Playbooks can be shared with your team, refined together, and approved as
versioned definitions to keep reviews consistent.
