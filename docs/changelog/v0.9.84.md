# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/cli](https://github.com/stella/stella/blob/v0.9.84/packages/cli/CHANGELOG.md), [@stll/auth-model](https://github.com/stella/stella/blob/v0.9.84/packages/auth-model/CHANGELOG.md): Require billing visibility for monetary operations and preserve hidden rates as null in time records.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.84/packages/ui/CHANGELOG.md): Add `MoveToSideIcon`, the side panel with a chevron pointing into it, for sending a view into the side panel, so it no longer draws the same glyph as the panel that shows or hides the side panel.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.84/packages/cli/CHANGELOG.md): Preserve own keys when building command trees, flags, schema examples and output summaries. Read nested input and output fields only from their owning records.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.84/packages/ui/CHANGELOG.md): Add caption appearance to menu and popover triggers and an inspector-row button size with the pane's fixed row rhythm. Caption controls retain their compact visible box while providing a coarse-pointer touch target.
- [@stll/template-conditions](https://github.com/stella/stella/blob/v0.9.84/packages/template-conditions/CHANGELOG.md): The root `@stll/template-conditions` entrypoint now exposes `evaluateCondition(expression, data, namedConditions?)`. Remove the fourth `_resolved` and fifth `_depth` arguments: cycle tracking and the 50-reference depth limit are owned by a private evaluation context. This is a breaking 0.7 release for callers that supplied those arguments; two- and three-argument calls retain their behavior.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.84/packages/cli/CHANGELOG.md): Support idempotent replay when attaching a source to a list item.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.84/packages/ui/CHANGELOG.md): Add the composer Button variant and fixed 28px icon-round size to both web and native renderers so chat, search, and assistant surfaces select the shared primary action through Button props.
- [@stll/auth-model](https://github.com/stella/stella/blob/v0.9.84/packages/auth-model/CHANGELOG.md): Add `AUTH_SIGN_IN_CODE_UNAVAILABLE_ERROR_CODE`, the error code for a sign-in code request that names an account signing in with a password.
