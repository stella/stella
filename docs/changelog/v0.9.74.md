# Maintenance release

stella includes reliability and maintenance improvements.

## Packages

- [@stll/auth-model](https://github.com/stella/stella/blob/v0.9.74/packages/auth-model/CHANGELOG.md): Expose a shared invitation lifecycle classifier for pending, past, and accepted invitations.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.74/packages/cli/CHANGELOG.md): Add `stella organization create` and request organization creation consent during CLI login.
- [@stll/auth-model](https://github.com/stella/stella/blob/v0.9.74/packages/auth-model/CHANGELOG.md): Export the opaque organization slug generator next to the shared slug rules.
- [@stll/agent-input](https://github.com/stella/stella/blob/v0.9.74/packages/agent-input/CHANGELOG.md): Normalize surrounding whitespace in slug inputs while preserving their lowercase token identity.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.74/packages/cli/CHANGELOG.md): Add statute provision links to matters for Czech and Slovak law through the API capabilities, MCP, and CLI.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.74/packages/ui/CHANGELOG.md): `BidiText`, `IdentityText` and `InspectorTitle` render text without directional controls, and `stripDirectionalControls` is exported for text that leaves the page.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.74/packages/cli/CHANGELOG.md): Add a team time report read capability with grouped recorded time and period summaries.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.74/packages/ui/CHANGELOG.md): A button no longer grows past its container. A one-line text label is cut with an ellipsis, and the button keeps its whole text as its accessible name; `layout="wrap"` keeps a label on several lines instead.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.74/packages/ui/CHANGELOG.md): Add `@stll/ui/collapsible` (`Collapsible`, `CollapsibleTrigger`, `CollapsiblePanel`) for a single disclosure, with the accordion's height motion and closed content kept findable by find-in-page. `Accordion` now keeps closed panels as `hidden="until-found"` by default (pass `hiddenUntilFound={false}` to unmount them), and `AccordionTrigger` gains a `trailing` slot for status text before its chevron.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.74/packages/ui/CHANGELOG.md): Table gains `density="compact"` for small reading tables: cells at text leading with no side padding, wrapping values, rows that do not highlight, and a row header that reads as the row's first cell. SearchField's clear button is unavailable while the field is disabled.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.74/packages/ui/CHANGELOG.md): `FacetBar` exposes its chips as a tab list with the active facet selected.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.74/packages/ui/CHANGELOG.md): `Form` documents how browser validation and server `errors` reach a field's `FieldError` (and why validation stays on submit), and exports a `FormErrors` type for the server error map.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.74/packages/ui/CHANGELOG.md): `TabsList` scrolls its active tab back into view when the strip is narrowed after mount.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.74/packages/ui/CHANGELOG.md): See package changelog for details.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.74/packages/ui/CHANGELOG.md): Use built-ins supported by the desktop's minimum WebView for calendar sorting and inline reordering.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.74/packages/cli/CHANGELOG.md): Keep provision-filtered case-law searches bounded. Exhausting the candidate budget returns a successful partial or empty page with a continuation cursor; only a statement timeout returns the retryable timeout response.
- [@stll/ai-catalog](https://github.com/stella/stella/blob/v0.9.74/packages/ai-catalog/CHANGELOG.md), [@stll/cli](https://github.com/stella/stella/blob/v0.9.74/packages/cli/CHANGELOG.md): Add `defaultTranscriptionModelId`, the cheapest transcription model offered in a region. The `dictation transcribe` capability no longer requires a model: without one the server uses that default for the organization's region.
- [@stll/fetch](https://github.com/stella/stella/blob/v0.9.74/packages/fetch/CHANGELOG.md): Return the transport's own `Response` for every timeout policy and remove the misleading transport-level `idle` policy. The new `@stll/fetch/body-reader` export reads a body with an idle deadline that restarts for each chunk and an optional byte limit: `iterateBodyWithIdleDeadline`, `readBodyWithIdleDeadline`, `readBodyTextWithIdleDeadline`, `readBodyJsonWithIdleDeadline` and `BodyByteLimitError`.
- [@stll/cli](https://github.com/stella/stella/blob/v0.9.74/packages/cli/CHANGELOG.md): `search.results.list` searches across the matters you can open, by text and filters, with `stella:read`. Assistant chat results need `stella:chat`.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.74/packages/ui/CHANGELOG.md): Add `BrowserControlIcon` to `@stll/ui/icons`: a browser window for stella acting in the user's own browser, distinct from the globe used for web search and page fetches.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.74/packages/ui/CHANGELOG.md): Remove the `reading`, `readingStrong`, `readingEmphasis` and `readingStrongEmphasis` text roles and the serif and italic text faces.
- [@stll/ui](https://github.com/stella/stella/blob/v0.9.74/packages/ui/CHANGELOG.md): Separator adds `ResizeSeparator`, a focusable strip that resizes the column beside it by pointer and arrow keys, and the sidebar adds `SidebarIdentityButton` for the footer's sign-in trigger.
