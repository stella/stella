# Mutation and query invalidation census

Baseline snapshot generated by `bun scripts/mutation-query-census.ts --write`, before the contract migration. The committed JSON is historical evidence; the guard analyzes current sources separately.

The syntax census records 392 mutation calls (189 direct TanStack calls; 203 wrapper invocations), 1354 reader calls, and 2761 production source files. Mutation analysis contains 161 explicit unresolved observations across 129 calls.

## Verified source gaps

- Cross-client entity rename: `workspace-realtime.ts` maps ENTITY to entity, task, and matter-overview keys. File readers in `lib/files/queries.ts` also expose file names, but that event policy does not refresh file metadata or content. The local rename callback already repairs these caches; another client only receives the event policy.
- Matter navigation: the navigation rail binds a new-chat action to its current matter prop. A reused rail can retain the parent matter binding during navigation. This is a caller-scope binding gap, separate from query invalidation.

## Analysis boundary

Route-family matches identify candidates, not shared entities, response projections, server events, or runtime callback execution. Dynamic key suffixes remain unresolved even with a known prefix. A missing local effect may be repaired by server events or another owner. The existing realtime resource policy is included as metadata; API-route to resource-event relationships are not inferred.

Imported and local function bodies are followed with argument bindings to a bounded depth. Higher-order returns, destructured parameter forwarding, computed API clients, and external implementations may remain unresolved. Every named mutation API and fixed-point-discovered wrapper invocation is retained, including unresolved options.
