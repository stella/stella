Dated exceptions are inventoried by `scripts/dated-waivers.ts`. CI annotates exceptions due within five days; existing owner checks continue to enforce expiry. A nightly workflow proposes one draft recheck PR when an exception is due, covering the next fourteen days, including expired entries.

The inventory reads documentation exclusions, Bun release-age exclusions and source annotations, dependency-audit acceptances, and temporary suppression waivers through their owners. The inventory and checklist preserve owner-written deadlines; date-only exceptions remain valid through their UTC expiry day. Ratchet allowances and other committed baselines currently have no dated expiry fields.

Documentation exclusions with an explicit HTTPS llms.txt URL in their explanation receive an HTTP recheck: 404 proposes a renewal using the existing review-window length; 200 registers the URL and removes the exclusion. Other responses, failed requests, and exclusions without a recorded URL remain unchanged and require review. Other waiver kinds are never renewed automatically.

When adding an expiry-bearing policy shape, extend `collectWaivers` through its owner parser and add an inventory fixture. The census test scans tracked policy/config files for literal expiry declarations and detects an unregistered source file. It cannot infer a new spelling, a computed expiry, or a review date stated only in prose; register those explicitly here and extend the census matcher. Historical dates, release timestamps, security.txt metadata, runtime credential expiries, and test fixtures are not waiver deadlines.

The workflow reserves `chore/recheck-dated-waivers` and its `-next` build branch. Proposals use the generating checkout's commit as their base, are signed through GitHub's commit API, updated in place, and left for review. The generated checklist is committed so a proposal containing only manual rechecks still has a reviewable diff. An unchanged checklist and documentation registry do not create another commit or PR. The workflow never arms automatic merging.
