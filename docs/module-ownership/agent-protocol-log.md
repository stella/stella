| `agent-protocol-log` — Logging the local agent engine's harness and sidecar protocol messages without their content | `packages/agent-engine/src/protocol-log.ts` | none        | One allowlist per message kind decides which fields of a Claude Code, Codex or desktop sidecar message reach `holder.log`, and how: closed values from closed lists the code owns, numbers, booleans, numeric versions and re-serialized instants as they are; ids and any other string in those fields as HMAC fingerprints under a random key each holder keeps in memory; and every other value as its kind and a power-of-two size band.
