| `chat-declined-tool-call` — Deciding whether the user declined a chat tool call | `packages/api-contract/src/chat.ts` | literal pattern `^User declined tool execution$` | A declined call is stored in one shape, the one the chat engine writes on a denial: an `error` call whose output is the engine's denial, keeping `approval.approved: false`, and a `denied` tool result. The API's own writer (`declineToolCall`) stores the same shape. Settlement, revisions, request validation, the stream's snapshots, the post-deploy smoke and the web cards read the decision through `isDeclinedChatToolCall`, never through a tool-call state, so a call declined before that shape existed reads the same. |
