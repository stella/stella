import registry from "../../../../../../../packages/cli/src/generated/registry-snapshot.json";

This page is generated from the committed tool-registry snapshot, the same
artifact the CLI's commands are generated from, so it cannot drift from the
deployed surface.

Access is the tool's declared behavior: **read** tools never change state;
**write** tools do and require confirmation in interactive clients;
**destructive** writes delete or irreversibly change data and always require
explicit confirmation.
