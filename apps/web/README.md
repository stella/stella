# Stella Web App

The Stella frontend application built with [TanStack Router](https://tanstack.com/router/latest).

## Getting Started

### Install dependencies

```bash
bun install
```

### Run the development server

```bash
bun --filter @stll/web dev
```

The application serves on [http://localhost:3000](http://localhost:3000) by default.

For a new or changed smoked route, add the `baseline:record` label to its pull request; CI records and commits the network baseline entry.
