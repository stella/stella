`Table` takes a `prose` density for tables of sentences read across columns (ruled columns and rows, padded cells set from the top, a quiet header in normal weight, an opaque sticky header) and a `cellText` prop (`wrap` or `single-line`) for how its cells set long text. `@stll/ui/icons` exports `ChartColumnIcon`, `ChartLineIcon`, `ChartNoAxesColumnIcon`, `ChartPieIcon` and `ChartScatterIcon`.
