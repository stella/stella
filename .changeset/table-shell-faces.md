`@stll/ui/table-shell` adds a sortable head's face for a loading view: `SortableHeadFace` (the label in the sort button's face and the arrow in its slot, with no behaviour), `TableHeadLabel`, `SortDirectionIcon`, `ariaSortOf`, `sortableHeadButtonClassName`, `HEAD_CONTENT_CLASS` and `SORT_ICON_SLOT_CLASS`. `SortableHead` in `@stll/ui/table` is built from the same pieces, so both phases share one set of classes. `InputFace` takes a `fieldClassName` for the line its placeholder sits on.
